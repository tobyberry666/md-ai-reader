# DSH MD 阅读

用户已于 2026-10-22 确认设计并授权实施。

## 产品

在 DeepSeek Harness Desktop 内增加独立的「MD 阅读」主页面。阅读区默认约 65%，右侧为当前文档的独立 DSH 原生会话，两栏可调节。文件选择和拖入均可打开 Markdown；文档保留原文、名称、阅读位置和关联会话 ID。每篇文档单独聊天，原有 DSH 任务不受影响。

阅读区采用简洁的书页排版，可收起目录，支持全文查找、代码高亮、公式和深浅主题。首版以阅读为中心，不增加编辑器、知识库、联网检索或自动摘要。

在渲染正文中选择文字后出现「提问」按钮。激活后保持选区，将原文作为可移除的引用放到右侧草稿，聚焦问题输入；用户发送后才调用模型。空选区不产生引用。代码块和表格中的文字也可引用。

## DSH 集成

通过插件机制注册主页面和入口，使用已安装的 DSH React、slots、sessions 和 conversation 服务。右侧复用原生会话视图与输入区，而不是另建直连模型 API。模型、推理、停止、工具与权限继续由 DSH 控制。文档会话使用独立 ID。

全文在该文档会话内注入上下文，携带文件名和明确的文档边界。所选文字与本次问题一起发送。导入、选择和阅读不触发模型。上下文状态区分未接入、接入中、全文已接入和失败；发送前检查全文接入成功。超过原生上下文能力时保留全文并明确报错，不用摘要或截断冒充全文。

Markdown 为用户数据；不执行 HTML 脚本，链接和图片使用 DSH 受支持的导航和文件机制。文档不能伪装成系统指令。插件卸载清理注册与监听，不删除会话历史。

## 验收

1. 在本机 0.2.1-rc.2 上加载插件并打开独立主页面。
2. 选择及拖入 MD；标题、目录、表格、代码、公式正常渲染。
3. 框选内容在右侧显示引用并能补充问题；引用文本准确。
4. 实际模型可以回答仅在文档末尾出现的随机测试事实，证明全文而非单独选区进入上下文。
5. 切换文档、重启后，各文档阅读位置与会话关联保持独立。
6. 超限、上下文接入失败、文件读取失败明确显示，失败不发送不完整问题。
7. 原生模型选择、流式回答、停止和已有主题兼容性分别检查；无法实测项在交付时注明。
